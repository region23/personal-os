# Personal OS

Скилл для ИИ-агента, который заводит вам личную базу контекста — «второй мозг» в обычных текстовых файлах.

Вы надиктовываете на ходу: «пробежал 10 км», «прораб перенёс плитку на среду», «надо до пятницы сдать отчёт». Агент сам раскладывает это по папкам, ставит сроки в `now.md` и записывает решения в дневник. В новом чате он сначала читает базу — и знает ваши приоритеты, сроки и историю, без пересказа.

Всё лежит в вашей папке в Markdown. Сегодня работаете в Codex, завтра открываете ту же папку в Claude Code или OpenCode — контекст на месте.

## Как начать

**Вариант 1 — без установки.** Скачайте репозиторий ([ZIP](https://github.com/region23/personal-os/archive/refs/heads/main.zip) или `git clone https://github.com/region23/personal-os.git`), откройте папку агентом с доступом к файлам и напишите:

> Прочитай SKILL.md и создай мою Personal OS в папке ../my-personal-os. Задай короткие вопросы для настройки, затем разбери мою первую заметку.

**Вариант 2 — как скилл.** Положите папку туда, где ваш агент ищет скиллы, и просто попросите «создай мою Personal OS»:

```sh
# Claude Code
git clone https://github.com/region23/personal-os.git ~/.claude/skills/personal-os
# Codex, OpenCode
git clone https://github.com/region23/personal-os.git ~/.agents/skills/personal-os
```

Агент спросит, как к вам обращаться, часовой пояс и для чего вам база. Отвечать на всё не обязательно. Потом расскажите одно реальное дело — например, «к пятнице подготовить доклад», — и он разложит его по местам.

Дальше просто открывайте папку базы агентом и рассказывайте, что происходит.

## Что получится

```text
my-personal-os/
├── AGENTS.md          правила для агента
├── README.md          карта базы и стартовая фраза для нового чата
├── now.md             фокус, сроки, ожидания — главная страница
├── me/                кто вы и как с вами работать
├── inbox/             сюда можно кидать неразобранное
├── journal/           дневник событий и решений по дням
├── system/            порядок работы и что подключено
└── .agents/skills/    inbox — разобрать входящее, weekly-review — обзор недели
```

Разделы под ваши темы — работа, здоровье, спорт, дом — появляются, когда о них заходит речь. Как это выглядит через пару недель — в [примере](example/README.md).

## Правила, на которых всё держится

- **Один факт — одно место.** В `now.md` только статус и ссылка; подробности — в разделе.
- **Текущее отдельно от истории.** README раздела — как есть сейчас; дневник и CSV только дописываются.
- **Агент замыкает петлю.** Изменилось решение или срок — он обновляет файлы до конца разговора и отвечает одной строкой «что → куда».
- **Только факты.** Неизвестное помечается `❓`, а не додумывается.

## Что важно знать

- Нужен агент, который читает и меняет файлы: Claude Code, Codex, OpenCode и подобные. Качество зависит от модели.
- Срок в `now.md` — не напоминание. Календарь и уведомления подключаются отдельно ([как](references/integrations.md)).
- База приватная. Перед тем как доверять агенту здоровье или финансы, проверьте, как ваш сервис обрабатывает данные. Git и бэкап — по желанию, агент предложит.
- Свою базу держите вне папки скилла — так её не заденет обновление.
- Переезд на другого агента или компьютер — [инструкция](references/portability.md).

## Для разработчиков

`scripts/bootstrap.py` — необязательный установщик шаблона без зависимостей (Python 3.9+), агент без Python создаёт файлы сам. Тесты: `python3 -m unittest discover -s tests -v`.

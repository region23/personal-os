# Подключения

Состояние на {{DATE}}. Установка шаблона сама не включает внешние сервисы

| Возможность | Статус | Что проверить или заполнить |
|---|---|---|
| Чтение и запись базы | ❓ | Проверить сохранением и повторным чтением первой записи |
| Git | Не настроен этим шаблоном | По желанию владельца; приватность репозитория, только свои изменения |
| Резервная копия | Не настроена этим шаблоном | Место, шифрование, частота, пробное восстановление |
| Календарь | Не подключён | Провайдер, область доступа, часовой пояс, проверка записи |
| Напоминания и фоновые задания | Не подключены | Планировщик, доступность хоста, подтверждение доставки |
| Импорт документов и приложений | Вручную | Источник, разрешённые данные, формат, защита от дублей |

После настройки указывай реальный механизм, дату проверки, ограничения и понятное владельцу подтверждение. Секреты хранятся в предусмотренном сервисом хранилище, в этой таблице — только их назначение и способ получить доступ. Детали конкретной интеграции оформляй отдельным файлом со ссылкой отсюда.

# Обзор недели

1. **Собери факты за 7 дней** в часовом поясе владельца: `journal/` за период, изменённые файлы разделов (если есть Git — `git log --since="7 days ago" --stat`), CSV с измерениями.
2. **Проверь сроки.** Каждую строку `now.md` → «Сроки» и «Ожидает ответа»: что просрочено, что горит в ближайшие 7 дней. Прошедший срок не значит, что дело сделано, — спроси.
3. **Сверь с фокусом.** Что реально продвинулось по каждому пункту «Фокуса», а что стоит.
4. **Выдай обзор до 12 строк:** сделано → горит → стоит → 1–3 фокуса на неделю (предложение, не решение) → до 5 вопросов, ответы на которые закроют `❓` в `now.md`.
5. **После ответов** обнови `now.md` и дату «Обновлено», закрытое убери из `now.md` (история остаётся в журнале и разделах), допиши итог в `journal/ГГГГ/ГГГГ-ММ-ДД.md`. Если Git выбран — коммит.

Готово, когда у каждого пункта `now.md` есть статус не старше двух недель и одно следующее действие названо.
